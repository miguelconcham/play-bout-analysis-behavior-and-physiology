SUPPORTING CODES V2 — ANALYZE FUNCTIONS
--------------------------------------------------------------------------------
Precomputed inputs for each Analyze_*.m in Figure 2/Supporting codes v2/.
Copied from Analysis results\Theta psth\ into the local folder above
when they were not already present.

1) Analyze_psth_all_behaviors.m
   Per-behavior delta PSTH (self vs partner) + LME.
   psth_structure : psth_structure_delta_all_behaviors_self_other_partner.mat
   animal_names   : animal_names_delta_all_behaviors_self_other_partner.mat
   results        : results_full_lfp_per_behavior.mat
   results (TW)   : results_full_lfp_per_behavior_time_warpped.mat
   Path           : Data\Analysis results\psth power by frequency and behavior\
   Loaded by      : Analyze_psth_all_behaviors.m
   Note           : results files are also saved by the same script (onset-aligned and time-wrapped LME)

1b) Analyze_psth_all_behaviors_theta_gamma.m
   Same LME as (1), for theta and gamma. Does not edit the delta script.
   Theta and gamma file names are listed under THETA #4 and GAMMA #4.
   Saved by       : Estimate_psth_all_behaviors_theta_gamma.m
                    (GENERATE_PSTH_ALL_BEHAVIORS_BANDS)
   Loaded by      : Analyze_psth_all_behaviors_theta_gamma.m

1c) Analyze_behavior_class_from_timewrap_power.m
   Classify two Type2 groups from mean time-wrapped band power.
   The first model pools electrode-1 events from every kept animal and
   every session, then cross-validates that pool. Leave-one-session-out
   is a later check.
   Loads the per-behavior PSTH mats above (delta, theta, or gamma).
   Default classes are Pounce (1) and PounceI (2), default model is LDA.
   Each event is a baseline z-score. Training folds use equal class counts.
   Loaded by      : Analyze_behavior_class_from_timewrap_power.m

2) Analyze_freq_coupling.m
   Cross-frequency coupling (delta phase vs gamma amplitude).
   psth_structure : couplig_structure_delta_gamma.mat
   animal_names   : animal_names_coupling_delta_gamma.mat
   Path           : Data\Analysis results\psth power by frequency and behavior\
   Loaded by      : Analyze_freq_coupling.m
   Note           : later sections also load per-animal LFP_PAG.mat and ChannelMap.mat
                    from NPX raw data (not this results folder)

3) Analyze_freq_coupling_maps.m
