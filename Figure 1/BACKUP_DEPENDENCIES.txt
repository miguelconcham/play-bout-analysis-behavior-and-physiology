================================================================================
7. PIPELINE ORDER (what generates what)
================================================================================

LDA pipeline:
  1. Obtain_Feature_USV_space.m (+ get_behavior_properties.m)
     -> writes numeric *.npy to locomotive / non-labeled folders
  2. REclassifiy_locomotive_behaviors.m
     -> saves all_behavior.mat, all_not_labeled_behavior.mat, all_var_names.mat
  3. Convolutional classification.ipynb
     -> trains autoencoder, saves embeddings and model weights
  4. (Trained separately) LDA classifiers
     -> LDA_PLAY_AGG_REG.mat, trainedModel_LDA_ALL_BEHAVIORS.mat
  5. Figure 1 LDA.m
     -> loads all of the above for plotting

HMM pipeline:
  1. CreateHMMFIiles.m -> Create_HMM_inputs.m
     -> HMM raw data\ (*.npy inputs, *_PropAndTime.mat)
  2. python hmm estimate.txt
     -> *_states_K*.npy, *_transmat_K*.npy, model_comp_*.npy
  3. CreateHMMFIiles.m -> Load_HMM_outputs_and_analyze.m
     -> HMM 2 and 3 states 2 partners\ (all analysis structs)
  4. Figure 1 HMM.m
     -> loads HMM outputs for plotting

Play bout pipeline:
  1. Figure 1 Play Bouts.m
     -> loads Behavior backups\*.txt directly, calls play_bout()
